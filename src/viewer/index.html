Two communities of AI labs, the same models and the same budget, race on the Lean problem set. Traditional: a lab's lemmas stay private until it proves a target; then the target and its lemmas are published and the lab takes the bounty. OSO: every result is published as soon as Lean accepts it, and value flows back to the results it used. Lean checks every proof.

Start a race of your own · choose the labs, their models and approaches, and the budget

Each lab is an AI model working on the problem set. Its approach is added to its instructions, like the simulated agent kinds; or write your own. Both communities get exactly the same labs and budget.

● live

Design your own experiment in two steps: the field agents work in, then the comparison: which rules, which parameters to vary, what to measure. Everything you save is a plain file in the repository (spaces/, config/experiments/, results/), the same as one made at the command line.

1. The field

A field is its research tree (results, what each builds on, how hard each is), its targets with bounties, and its words for things. Use one that exists, describe a new one and let a model draft it, or write the file yourself.

Read its report
A model (Claude Opus 5.5, through the key in .env) writes the file; it is checked and test-run, and errors go back to the model. Costs a few cents. You review it before saving.
Every setting is documented in config/scenarios/default.yaml; a small field can list its results one by one, like the battery field.

2. The experiment

Each combination of a rule setting and the values you vary is one row of the result; each row is run many times with different random draws. The field's agents and budget are the same in every row.
